# Clear Kayak Tour and Subpage Build Plan

## Purpose

Build out the website beyond the homepage, with the tour experience as the
primary conversion path. The new pages should help mobile visitors quickly
understand which experience fits them, what to expect, where tours operate,
and whether they should book online or call to request a tour.

This document separates confirmed direction from information that still needs
client confirmation. It is a planning source of truth and does not authorize
publishing unconfirmed tour schedules, prices, or launch addresses.

## Confirmed Brand And Experience Direction

- Mobile-first layouts because most visitors use mobile devices.
- Larger, readable typography.
- Water or mangrove backgrounds.
- Water should feel clear, blue, sunny, and inviting.
- Use motion only when the video authentically represents the tour and does
  not hurt readability or performance.
- Emphasize 100% clear kayaks.
- Emphasize small groups and local guides.
- Describe guides as educationally oriented.
- Emphasize beginner and family friendliness.
- Primary search phrase: "Clear Kayaking Jupiter."
- Optimize page copy for conventional search and AI-assisted search.
- Use relevant structured data.
- Keep booking actions prominent and easy to use on mobile.

## Image And Video Plan

The Drive contains a large library of authentic JPG photos, MOV clips, a
`CK_Hero.mp4`, current-site captures, gift-card concepts, and a brand guide.

### Asset workflow

1. Inventory and visually review all authentic photos and videos.
2. Tag assets by tour, location, wildlife, guide, group type, orientation, and
   quality.
3. Select two to four strong authentic images per tour.
4. Select one hero image per tour with room for readable text.
5. Adjust exposure, contrast, white balance, and color so water feels clear,
   blue, and sunny while remaining believable.
6. Crop responsive desktop and mobile variants where needed.
7. Convert final website assets to optimized WebP or AVIF.
8. Write accurate alt text.
9. Use video only if it authentically depicts the actual customer experience.
10. Use AI generation only for a genuine content gap and label the asset
    internally so it is not mistaken for documentary wildlife evidence.
